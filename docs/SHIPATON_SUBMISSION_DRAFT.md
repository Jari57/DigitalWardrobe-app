# FitStalker submission draft

Status: editable preparation only. Not submitted. Store release, RevenueCat integration and event eligibility remain unconfirmed.

## Name and one-line pitch

**FitStalker — Turn outfit inspiration into your next look.**

Find clothing from a screenshot, explore visual shopping results, and put together outfits with pieces in your own closet.

## Project description

Outfit inspiration is everywhere, but identifying individual pieces and deciding what works with clothes you already own takes effort. FitStalker connects screenshot discovery with a private digital wardrobe.

Users upload a reference, select a detected garment, and see product photos and shopping links. When evidence cannot establish an exact match, results are presented as alternatives. Users can also save inspiration and build outfits from their own wardrobe.

The current application combines image analysis, product search, retailer metadata and visual comparison. It keeps private images behind authenticated access and checks ownership when serving shopping photos. Shopping availability depends on retailer coverage; the application does not guarantee an exact match for every screenshot.

Our next focus is improving direct-retailer and regional coverage with independently reviewed examples. Live viral discovery is a planned extension requiring a connected social-data source; it is not a demonstrated feature today.

## Demonstration storyboard (target 110 seconds)

| Time    | Screen and action                                      | Narration purpose                                              |
| ------- | ------------------------------------------------------ | -------------------------------------------------------------- |
| 0–12s   | Open the actual app on the intended device             | Explain the screenshot-to-outfit problem                       |
| 12–35s  | Upload a permissioned outfit image; select one garment | Show detection and the selected item                           |
| 35–58s  | Show actual photo results and follow one retailer link | Demonstrate the result; use the actual match/alternative label |
| 58–80s  | Open a prepared, consented closet; build an outfit     | Connect inspiration to clothes already owned                   |
| 80–95s  | Change discovery audience, refresh and save a look     | Show visible state changes and persistence                     |
| 95–110s | Reopen the saved outfit and show the owned pieces      | Prove the useful result persists                               |

Rehearse first, but record real responses. Do not replace a failed search with fabricated cards, invent an exact match or label editorial stories viral. Disclose edited waiting time. Use owned/permissioned reference and wardrobe images, not the private evaluation photo by default. Billing remains off. Do not add a purchase segment without a changed product decision.
