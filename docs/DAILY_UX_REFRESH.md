# Daily UX and feed recovery

For You previously read persisted articles without recovering a missed cron refresh. Returning to an open page did not fetch again, and users had no refresh action. The API now attempts an overdue refresh on reads, using the existing global lock and 45-minute cooldown. Authenticated manual refresh has a 12/hour per-account limit and the existing five-minute global forced-refresh cooldown. Saved-only reads do not fetch publishers.

Publisher redirects are bounded to three and restricted to the original HTTPS host (including its www variant). Empty current fashion coverage is treated as unavailable instead of falsely advancing successful freshness. Existing articles and saves remain intact during failures. The UI shows delayed freshness, reloads when returning after a minute and every five minutes while visible, and offers Refresh feed. It distinguishes newly returned ideas, unchanged coverage, and unavailable sources. None of these actions call AI. This does not guarantee publishers release new stories each refresh.

Four primary destinations replace six: Spotter, For You, Closet, My fits. Canvas and Stats remain accessible from Closet. Two primary choices lead the experience: Put a fit together opens the closet-based styling dialog; Stalk a fit opens and scrolls to screenshot shopping. Saved fits remain secondary, and Add a piece lives in Closet. The former Blind Fit dialog now leads with plans, accepts up to 120 characters of occasion/context, and saves the chosen outfit directly through the existing owner-scoped outfits API. Canvas editing and free shuffle remain optional. AI generation remains explicit and metered; no model, budget or schema changes.

Verification: production webpack build and TypeScript checks pass; three targeted tests cover same-origin authentication, bounded publisher redirects/empty responses and mobile plans-to-stylist-to-save plus feed refresh, unchanged-result feedback, four-tab navigation, and 320px overflow. UI tests use deterministic API fixtures, not real provider inference or production database writes. Existing affected browser selectors are updated, but the full database-backed suite was not rerun in this restricted environment.

No claim of live deployment or solved upstream publisher availability is made by this document.
